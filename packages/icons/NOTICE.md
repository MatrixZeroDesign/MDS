# MDS icon drawing notice

The SVG drawings in this package are hand-authored for Matrix Design System.
They do not import, embed or copy Lucide SVG path data. React is an external
peer dependency and is distributed under its own license.

Lucide informed the choice of familiar semantic names and the general goal of
clear, rounded outline icons. It is a design reference, not the source of the
SVG implementations distributed by this package. Basic signs such as plus,
minus, arrows and checkmarks use conventional geometry; no exclusive claim is
made over those common symbols.

The earlier prototype used lucide-react wrappers. Those wrappers and their
underlying drawings have been replaced in this source revision. Licenses and
attribution required by any older distributed revision still apply to that
revision.
