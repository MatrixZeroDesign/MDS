# Changelog

## 0.1.0-alpha.1

- Add 386 optically normalized brands across AI, products, mobility, commerce, infrastructure, security, data and Web3.
- Provide color and monochrome variants with low-contrast fallbacks for light and dark surfaces.
- Use compact marks by default and expose official wordmarks for brands that provide them.
- Support named components and dynamic `BrandIcon` lookup with tree-shakable package exports.
